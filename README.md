## SignalZero ScamShield

This is a submission to HackUTD: Zero Day, which ran from November 7–8, 2026. Please see more information [here](https://devpost.com/software/t-mobile-scam-game) about the project.

### Hosting Instructions

Remember to run `python3 -m pip install -r requirements.txt` in your Python virtual environment to install the dependencies!

If you're self-hosting, you'll need a DeepSeek API key. Run the frontend with, for instance, `DEEPSEEK_API_KEY='sk-...' python3 app.py`

Classifier training was tested in Python 3.11.
